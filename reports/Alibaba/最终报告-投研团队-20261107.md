## 4. 各维度分析摘要

**商业模式（段永平视角）**
1. 账本上，阿里仍是"用电商利润养 AI 和即时零售"：电商 EBITA 约 397 亿元/季，AI 实验室 −139 亿元/季。
2. 客户管理收入 −7%，同时闪购补贴从销售费用改记为收入抵减。**货币化率在下降**，这是收费权减弱的证据，不只是"承压"（较 10-20 报告更进一步）。
3. 闪购对主站的协同：没有披露留存和复购。如果导流有效，客户管理收入不应在闪购最猛时负增长（推测）。
4. AI 闭环只在"云卖算力"这一段被证实（AI 相关收入连续 12 个季度三位数增长）；"千问 → 电商"没有披露 GMV 或转化数据，目前是叙事。
5. 6 月季度分部合并后，淘天单独利润率不可见，透明度下降。

**财务（巴菲特视角）**
1. 利润质量偏低：FY26 利息及投资收益 875 亿元，高于 GAAP 经营利润 502 亿元。
2. FCF 从 FY24 的 +1,505 亿元转为 TTM −766 亿元，负值仍在扩大；单季 capex 677 亿元，进度快于 3,800 亿元计划。
3. 三年三情景（工具）：乐观 +20%/26x → $186（+70%）；中性 +10%/20x → $110（+0.7%）；悲观 0%/14x → $58（−47%）。
4. 中性情景三年回报接近零。安全边际依赖 forward 13.8x 所隐含的利润修复，不靠当前利润。反面：补贴收缩后 EPS 可能快速回升，26x 会夸大"贵"的程度。

**行业（芒格视角）**
1. 1–9 月网上商品零售 +3.8%（上半年 +4.8%），社零 +1.1%（统计局 2026-10-19，新浪转载一致）。电商已是低个位数增长的存量市场。
2. 补贴战"边打边收"：美团 2025 年由盈转亏（预告 −233 至 −243 亿元），2026Q1 经营亏损收窄到 65 亿元；市场监管总局转发《外卖大战该结束了》；阿里称闪购投入"下季度显著收缩"，目标本财年 UE 转正。
3. AI 云：阿里收入份额第一（Omdia 37%），但火山引擎按 token 量第一（IDC 49.2%）。口径相差 10pp 以上。
4. 大模型 App 月活（QuestMobile 6 月）：豆包 3.82 亿 / 千问 1.67 亿 / DeepSeek 1.30 亿。千问 C 端心智落后豆包一倍以上。
5. 最大隐性威胁：购物入口从"淘宝搜索"迁到"豆包或微信 agent"；阿里自己做 agent 也会蚕食搜索广告。

**风险与管理层（李录视角）**
1. **1260H**：2026 年 6 月五角大楼将阿里列入"中国军方企业"清单；阿里 6-23 起诉，获得针对游说限制规则的临时禁令，但未被移出清单。下一步风险是投资限制和指数剔除（推测）。
2. **增发**：8 月 7.10 亿股，6 月季度回购仅 $1.62 亿。"持续回购"论点被证伪，这是本轮最大的负面修正。
3. **外卖补贴规范**：市场监管总局 2026-06-17 发布征求意见稿，禁止长期大额补贴和低于成本销售；正式稿未查到。对利润是利好，对份额扩张是限制。
4. **13F**：喜马拉雅 2026Q2 持仓无 BABA，PDD 占 22.2%。13F 不覆盖港股，只能作旁证。
5. 十年情景（推测）：中国版"亚马逊+AWS" 30% / 平庸公用事业 45% / 价值毁灭 25%。

## 5. 投资论点

🟢 **看多**
1. AI 云收入 +45%，收入份额第一；芯片、云、模型全栈（平头哥 + Qwen 开源生态）。
2. 补贴战在监管下降温，闪购亏损有望收窄，EPS 弹性大（forward 13.8x）。
3. 现金 + 短投 4,745 亿元，加战略投资（蚂蚁 33% 等），为下行提供缓冲。
4. 网上服务零售 +5.3%，快于商品，本地生活资产有增量。
5. 中国 AI 政策支持，国产算力替代需求利好阿里云。
6. 如果 AI 云在 2027 年前证明 capex 有两位数回报，当前约 1.8x PB 可能低估。

🔴 **看空**
1. 客户管理收入 −7%，货币化率下降，电商收费权减弱。
2. FCF −766 亿元（TTM）且在扩大，需要外部融资（8 月增发）。
3. 主营经营利润率 2.9%，利润大头来自投资收益。
4. 美国 1260H 已列名，可能升级为投资限制，GPU 获取受限。
5. 千问 C 端落后豆包，agent 购物入口可能被字节或腾讯截走。
6. 分部合并降低透明度（淘天利润率、国际盈亏不可见）。
7. 闪购收缩后若订单回流美团，约千亿级投入只买到一张"入场券"。

## 7. 最终投资建议

**定性判断**

| 维度 | 判断 |
|---|---|
| 生意质量 | 好资产在换挡：旧现金牛衰减，新护城河还不产生现金 |
| 管理层 | 方向清晰、执行有力；资本配置纪律让位于战略 |
| 估值 | 按 TTM 不便宜；便宜与否取决于利润修复 |
| 时机 | 9 月季报（11 月中下旬）前不宜动作 |

**分层操作建议**

| 类型 | 建议 | ADR 价格 | 港股价格（按 7.78 汇率 /8 折算） |
|---|---|---|---|
| 激进型 | 季报确认补贴收缩后小仓（≤3%） | ≤ $100 | ≤ HK$97 |
| 稳健型 | 分批建仓（≤5%） | ≤ $90 | ≤ HK$88 |
| 保守型 | 等待深度安全边际 | ≤ $75 | ≤ HK$73 |
| 持仓者 | 持有不加仓，等季报 | 卖出参考 ≥ $150 或 1260H 升级为投资禁令 | — |

**加仓信号（9 月季报验证点）**
1. 客户管理收入同比转正。
2. 闪购 UE 转正、AI 实验室亏损收窄。
3. 云 EBITA 利润率站上 12%。
4. FCF 负值收窄，且没有进一步增发。
5. 四家平台合计销售费用同比下降（摩根大通提出的检验指标）。

**减仓信号**
1. 1260H 升级为美国投资禁令或指数剔除。
2. 再次股权融资。
3. 客户管理收入连续两个季度负增长。
4. 补贴收缩后闪购订单份额明显回落。
5. 云增速跌破 25% 而 capex 不降。

## 8. 总结

阿里没有崩塌，但正处在一次代价高昂的换挡中：电商这台老现金牛的收费权在下降，AI 云这台新引擎在变强，但还在吃掉全部经营现金流，连增发都需要。10-20 以来，风险端恶化了三件事（1260H 列名、增发、FCF 扩大负值），改善了两件事（补贴监管降温、云提速）。约 25 倍 TTM PE 所买的不是今天的利润，而是对利润修复的预期。在 9 月季报验证补贴收缩和 capex 回报之前，这份预期没有足够证据支撑。**观望；ADR $90 / HK$88 以下开始有吸引力。**

## 1. 一句话结论

> MTCH 是一家资本轻、ROIC 约 25%、扣除 SBC 后 FCF 收益率约 10% 的现金牛，但收入已停滞两年。近期利润扩张主要来自应用商店抽成下降，而非产品复苏。当前价格公允、不便宜：**观望，$32 以下分批，$28 以下才有厚安全边际。**

## 4. 各维度分析摘要

**商业模式（段永平视角）**
1. 直接收入占 98.4%，广告仅 1.6% 且同比 −17%。没有广告兜底，也无法像 Meta 那样把价格打到零。
2. **非共识①**：Q3 营业成本 −16.4%（−$40.5M），相当于经营利润增量（+$47.3M）的约 85%。利润扩张主要来自渠道税下降（推测为替代支付绕开应用商店抽成），而非 Tinder 复苏。
3. Hinge 收入 +19.5%（+$35.9M）抵不过 Tinder −$10.6M 与 Everyone Everywhere −$45.4M。**非共识②**：EE 的拖累大于 Tinder，Tinder 止跌也不足以让总收入转正。
4. Tinder 飞轮倒转三年（女性用户流失 → 男性体验变差）；9 月 DAU 首次同比转正，但付费用户仍 −4%，止跌未证实。
5. 护城河：转换成本 ★1、网络效应 ★2（下调）、规模 ★4（上调）。**非共识③**：护城河在规模与多品牌组合，不在网络效应。

**财务（巴菲特视角）**
1. 营收停滞，EPS 从 2.02 升到 2.94（+45%），驱动是利润率与缩股（2025 年初至今 −10%）。
2. 股东权益为负（回购 + IAC 分拆会计），ROE 无意义；ROIC 24.7%，但商誉使分母偏低。
3. 债务再融资成本上移：2026 年到期的 0.875% 票据被 6.125% 的 2033 债替代。$2.3B 低息债若按 6% 重置，年利息约多 $40M（估计，约占净利润 5%）。属于缓慢侵蚀，不是危机。
4. 回购纪律 2023 年后才改善：Q4'25 均价 $32.94、2026 年 1–9 月约 $35，均低于现价；2022 年回购大概率在 $60–100（推测）。

**行业（芒格视角）**
1. 机构报告称行业 CAGR 7–8%，但上市公司实际为负（MTCH −2.5%，Bumble −15.9%），两者背离。
2. 增量流向细分：Grindr +22.1%（10-Q 与股东信两源一致）、Feeld +31%、Raya +64%（2024，iOS）。
3. 替代支付节省：2026 年指引 $110M（2026-02 上调，8-K 两期一致）。这是监管红利，Epic v. Apple 发回重审，存在逆转风险。
4. AI 创业公司合计融资不足 $32M；MTCH 是 Overtone 的投资方，形成对冲。

**风险与管理层（李录视角）**
1. 已知和解与罚款约 $86M+（FTC $14M、年龄定价集体诉讼 $60.5M、爱尔兰 DPC €11M），不足一年 FCF 的 8%。
2. Rascoff：降本与产品节奏执行力强；Zillow Offers（其任内推出，2021 年关停，减记 $4.08 亿）显示对重资产新业务过度乐观的倾向。
3. 单一类股、内部持股 0.64%；Elliott 曾持股约 $10 亿并获 2 个董事席位，2026 年持仓未查到。
4. 十年基准情形（40–50%）：Hinge 成为主力，Tinder 缩为现金牛；AI 颠覆滑动范式约 30%（推测）。

## 5. 投资论点

🟢 **看多**
1. SBC 调整后 FCF 收益率 10.1%，加股息 2%，每年缩股约 4%。
2. Tinder DAU 9 月同比转正，3.5 年来首次。
3. Hinge 收入 +19.5%，付费用户 +23%，2027 年 $10 亿收入目标。
4. 应用商店费用节省约 $110M/年，属于结构性台阶。
5. 激进投资者约束资本配置，近期回购价格低于现价。
6. 在西方上市同业中份额约 72%，Bumble 衰退更快，龙头相对受益。

🔴 **看空**
1. 收入连续三个季度不增长，Q4 指引 −1% 至持平。
2. 利润扩张主要来自成本端一次性改善（裁员、渠道税），不可外推。
3. 网络效应依赖女性用户密度，而这正是流失最严重的部分。
4. Everyone Everywhere −20%，拖累大于 Tinder。
5. Hinge RPP −3%，靠低价地区扩张拿量。
6. 低息债按 6%+ 重置；净杠杆 2.0–2.5x，不是巴菲特式的"几乎无债"。
7. AI 原生约会、线下社交、年龄验证立法，三条可能的需求侵蚀路径。

## 7. 最终投资建议

**定性判断**

| 维度 | 判断 |
|---|---|
| 生意质量 | 好现金生意、弱护城河、不确定的增长生意 |
| 管理层 | 合格，产品端拐点未证明 |
| 估值 | 公允：三年中性 +1.7% ~ +2.7%（加 2% 股息），上下行 +46%~+62% / −46%~−48% |
| 时机 | 不急：Q4 营销加码期 EBITDA −11%；关键看 2027 年用户改善能否转化为收入 |

十年压力测试（基础报告）：r=10% 下期望 IRR 3.94%，±2pp 不翻转。财务分析师指出净利润锚偏保守，应介于净利润与 SBC 调整后 FCF 之间；即便上调，仍难覆盖 r。**结论：只约束仓位，不单独决定回避。**

**分层操作建议**

| 类型 | 建议 | 价格区间 |
|---|---|---|
| 激进型 | 小仓试探，≤组合 3% | ≤ $36 |
| 稳健型 | 分批建仓，≤5% | ≤ $32 |
| 保守型 | 等待深度安全边际 | ≤ $28（约 7x SBC 调整后 FCF） |
| 持仓者 | 持有不加仓，仓位上限 5% | 卖出参考 ≥ $50 |

**加仓信号**
1. Tinder 付费用户同比转正。
2. Tinder DAU 连续 3 个季度同比正增长。
3. Hinge 2027 年收入达到 $10 亿，且 RPP 止跌。
4. 营业成本占收入比维持在约 23%，证明渠道节省可持续。
5. 股价跌破 $30 而基本面未恶化。

**减仓信号**
1. Tinder 付费用户降幅扩大到 −8% 以上。
2. Hinge 增速跌破 10%。
3. Epic v. Apple 重审后苹果对外链收佣，渠道节省回吐。
4. 高杠杆大额收购，或净杠杆升至 3x 以上。
5. 重大用户安全事件引发品牌冲击。

## 8. 总结

MTCH 的真实面貌，是一家正在从"增长股"变成"现金股"的公司。轻资产、ROIC 25%、扣除 SBC 后每年仍能产生约 $9 亿现金，这是真实的价值。但 Q3 利润增长的大头来自应用商店抽成下降，而不是用户回流；网络效应因女性用户流失而减弱；Everyone Everywhere 的衰退抵消了 Hinge 的增长。按巴菲特的标准，这是"以合理价格买一家普通公司"，不是"以合理价格买一家伟大公司"。在 Tinder 付费用户止跌之前，$39 的价格提供的只是估值层面的安全边际，不是确定性层面的安全边际。
